# Contributing

Thank you for helping maintain Awesome Lifelong Agents.

## Scope and evidence

- Prefer original papers, author-maintained project pages and official repositories.
- Explain what persists across trials/tasks and what feedback updates it.
- Label one-task refinement and general memory architectures as related work when lifelong evaluation is absent.
- Do not claim reproduction or improvement without reproducible evidence.
- No paid placement, star trading, tracking links, copied abstracts or unsupported “best” rankings.

## Add or update an entry

1. Edit both README.md and README.zh-CN.md in the matching section.
2. Use the canonical paper URL, exact title and first arXiv submission year.
3. Include parameter-update status, retained state, and a short original description with a limitation.
4. State the primary source used for verification in the PR. Add code links only after confirming authorship.
5. Run `python3 scripts/check.py`. CI checks structure, local links and bilingual paper parity—not scientific correctness or external URL availability.
6. Keep changes focused; disclose affiliations with submitted projects.

By contributing original content, you agree to publish it under the repository's CC0 dedication. Linked works retain their own licenses.
Be respectful; critique claims and evidence, not people. Report factual errors with sources.
